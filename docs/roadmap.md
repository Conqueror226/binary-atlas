# Roadmap

These are planned directions, not completed capabilities or personal achievements.

## First reproducible investigations

- Record the actual lab platform and C/assembly baseline.
- Complete a small branch-boundary investigation and preserve outputs.
- Trace memory behavior and explain one bounds-check failure and repair.
- Publish the first clean-rerun report with actual evidence.

## Build a useful portfolio

- Connect a toy executable's behavior to Windows event evidence collected in the lab.
- Add a parser investigation with repeatable test inputs and a bounded conclusion.
- Compare Ghidra hypotheses with debugger observations.
- Use Python to automate hashes, metadata and reproducible analysis steps.

## Extend after the foundations

- Evaluate fuzzing and test minimization on an owned parser.
- Model sample/function/evidence relationships in Neo4j.
- Improve report rendering, evidence navigation and resource freshness checks as needs emerge.
- Evaluate optional storage or authentication separately if cross-device synchronization becomes necessary.
