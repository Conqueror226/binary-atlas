# Write an evidence-led project report

Status: starter exercise; not completed portfolio work.

Turn a completed investigation into a reproducible and appropriately scoped portfolio entry.

Scope: owned or explicitly authorized programs in an isolated lab. Commands describe the stated lab environment, not every host platform.

## Investigation steps

1. Choose a project you actually completed. Use the Portfolio section to create a draft. Suggested projects are ideas until you add your own work.

2. Record your question, scope and authorization, sample/source provenance, SHA-256 values, tools, reproduction steps, observations, and limitations. Redact personal data.

3. Perform a clean rerun. Only mark the entry self-verified when the required evidence exists and you have checked it. This is your attestation, not independent validation.

## Evidence and validation

- A complete report and evidence references
- A clean reproduction result
- Limitations and verification date

## Learning output

A reviewable project entry with honest verification status.
