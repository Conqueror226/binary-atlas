# Build a small function map

Status: starter exercise; not completed portfolio work.

Distinguish file metadata, disassembly, and decompiler interpretation.

Scope: owned or explicitly authorized programs in an isolated lab. Commands describe the stated lab environment, not every host platform.

## Investigation steps

1. Import your own branch binary into Ghidra after confirming the target and file format. Keep its hash and build settings.

2. Find main and classify. Rename one symbol, annotate the branch, and compare decompiler output with instructions.

3. Inspect imports and strings. Write one hypothesis and an alternative explanation. Static presence alone does not establish runtime behavior.

## Evidence and validation

- Binary SHA-256 and import settings
- Annotated function map
- A hypothesis and an alternative

## Learning output

A small map that separates observations from inferred behavior.
