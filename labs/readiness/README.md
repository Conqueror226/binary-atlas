# Map your starting point

Status: starter exercise; not completed portfolio work.

Record your current knowledge without turning prior cybersecurity experience into assumed low-level proficiency.

Scope: owned or explicitly authorized programs in an isolated lab. Commands describe the stated lab environment, not every host platform.

## Investigation steps

1. List one concrete task you have completed with Python, Windows event logs, Security Onion, Neo4j, digital forensics, and identity security. Add an evidence reference if available.

2. For C, pointers, assembly, debuggers, and PE/ELF, record: not tried / learning / independently practiced. Unknown is a valid answer.

3. Pick one knowledge gap and a weekly study time that fits your schedule. The suggested lab durations are estimates, not deadlines.

## Evidence and validation

- A dated baseline note
- One learning question
- Your own availability estimate

## Learning output

A clear baseline and a learning question you can revisit.
